## Context

`AccountCard.vue` 行尾有四个 `p-1.5` 图标按钮（余额刷新、设为当前凭证、立即签到、删除）。「设为当前凭证」按钮当前带 `v-if="!account.isActive"`，当前凭证卡片上该按钮消失，行尾少一个图标位，导致图标列与其他卡片错位。上一轮 change 已把四个操作统一为图标级别，本次补齐对齐与激活态呈现。

约束：沿用既有样式范式与 Tailwind v4 class，不引入新依赖、不新增绑定方法。

## Goals / Non-Goals

**Goals:**
- 「设为当前凭证」图标在所有卡片上常驻，消除行尾错位。
- 当前凭证卡片上以高亮激活态区分「已激活」与「可切换」。

**Non-Goals:**
- 不改「✓ 当前凭证」徽章（已表达激活状态，与本次图标高亮并存）。
- 不给激活态加 `disabled`（保持幂等可点击）。
- 不改其余三个图标按钮、不改 `setActive` action 与绑定方法。

## Decisions

### 激活态样式

| 方案 | 样式 | 取舍 |
|---|---|---|
| A | 仅 `text-indigo-600 dark:text-indigo-400` | 改动最小，但静态亮色与 hover 色相同，激活态与 hover 态视觉难以区分 |
| **B（选定）** | A + `bg-indigo-50 dark:bg-indigo-500/20` 胶囊底色 | 静态底色让激活态脱离「灰图标」基准，且与 hover 底色（slate）区分，醒目 |
| C | `fill-current` 实心 Pin | 视觉最突出，但与「✓ 当前凭证」徽章语义重复 |

选用 B。

### 实现方式

移除 `v-if="!account.isActive"`，改用 `:class` 按 `account.isActive` 条件拼接亮色与底色 class；`title` 与 `@click` 保持不变。class 拼接沿用同文件删除按钮/签到按钮的写法。

替代方案：保留 `v-if`、用 `v-else` 渲染一个占位空元素——被否，引入无意义节点，不如单按钮条件 class 简洁。

## Risks / Trade-offs

- [激活态仍可点，用户可能困惑「再点会怎样」] → 操作幂等、无副作用，且 spec 已有「设为已存在的当前凭证」场景；接受。
- [高亮图标与「✓ 当前凭证」徽章双重表达同一状态，略冗余] → 徽章表达状态归属，图标高亮保证列对齐与激活手感；接受。
- [颜色对比度在暗色模式下不足] → 沿用文件内既有的 `dark:` 亮色搭配（与其他 indigo 高亮一致），接受。
